## 功能说明
- 支持 4 个天体预设场景：地球、月球、木星、太空
- 重力可通过滑块精细控制，并支持平滑过渡
- 自动保存用户配置到 `localStorage`
- 刷新页面后自动恢复上次参数
- 适配桌面端与移动端触屏交互

## 运行方式
1. 打开 `index.html` 文件；
2. 或启动本地静态服务：
   ```bash
   python -m http.server 8000
   ```
3. 浏览器访问 `http://localhost:8000`。
